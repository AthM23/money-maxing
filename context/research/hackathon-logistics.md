# HackMIT 2026 logistics that affect the build

## Hard deadlines (Eastern time)
| When | What |
|---|---|
| **Sat 11:59 PM** | Create or join the project on Plume. A rough name is enough. Miss it and the team cannot be judged. Zone and table are emailed overnight. |
| Sun 1:00-7:00 AM | Venue closed. |
| **Sun 11:00 AM** | Hacking stops; full submission due on Plume. |
| Sun 12:00-2:30 PM | Expo judging. Sponsor challenge judging runs in the same block (12:30-2:10 PM at JAC). |
| Sun 2:45-4:45 PM | Panel judging for selected teams. Closing 5-6 PM. |

Presentations: 5-7 minutes at the table, leaving time for questions. Most teams use a few slides and a demo.

## Judging
- **HackMIT overall:** Innovation 30 · Technical complexity 30 · Impact 30 · Learning and collaboration 10. Theme tracks are Sustainability, Education, Interactive Media, Healthcare; none fits, so enter without a track.
- **Maximor:** see maximor-track-brief.md. Sponsor challenges are separate from theme tracks and stack: one project can enter several.

## Prizes this project can stack
| Sponsor | Prize | What it needs from us |
|---|---|---|
| **Maximor** | $4,000 / $2,000 / $1,000; top 5 teams fast-tracked to interviews | The brief. Show learning across runs; a one-shot chatbot or hard-coded workflow is "not enough". |
| **Ramp** | $100 per member across three places, plus hardware | "Save Time. Save Money." Same demo. |
| **Token Company** | $500 | Optimize and document LLM cost inside the product. Our cost per decision before and after compile. |
| **OpenAI** | credits and swag | Use the API, and **name one concrete way Codex helped** in the demo. Plan: GPT is the independent controller; Codex writes the kernel's test suite. |
| Deepgram | a Nintendo Switch per member | Only if we actually call a Deepgram API (voice answers to escalations). Stretch. |

Not stacking: Visa (consumer shopping brief), Meta (needs a public repo, a video and a write-up for a different brief).

## Rules worth remembering
- A search result summarised HackMIT's rule as: planning beforehand is fine, project code is written during the hacking window. The official wording could not be loaded (the site is script-rendered). This repo starts from zero code, which keeps it simple.
- Report real numbers only. The Syndicate winners all published a number against a named baseline; see syndicate-hackathon-analysis.md.
